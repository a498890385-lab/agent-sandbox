# AGENTS.md

This repository is a sandbox for a coding agent. Every change should be small and reviewable.

## Commands

- Run `npm test` before you finish. It runs `node --test`.
- There is no install step and no dependency. Do not add one.

## Rules

- Change only files under `src/` and `test/`, plus `README.md`.
- Do not touch `.github/`, `AGENTS.md`, or `package.json`.
- One pull request does one thing.
- If a request needs a design decision, ask instead of guessing.
- Never commit secrets, tokens, or machine-specific paths.
